Exploration by Random Network Distillation

Original Authors: Yuri Burda, Harrison Edwards, Amos Storkey, Oleg Klimov  ·  OpenAI & University of Edinburgh  ·  ICLR 2019
💡
"RND generates intrinsic rewards by measuring prediction error of a randomly initialized fixed target network — novel states are harder to predict, thus rewarded more, driving deep exploration without any hand-crafted bonus."
01 · Problem

The Exploration Challenge

Reinforcement learning agents fail in sparse reward environments — they cannot stumble upon rewards by chance in large state spaces.

Classic ε-greedy and random policies are insufficient when rewards are separated by thousands of steps from any meaningful action.

The Hard Exploration Problem 𝔼[R] ≈ 0  ⟹  No gradient signal
∴ Policy π learns nothing useful
  • Montezuma's Revenge: rooms separated by lethal traps
  • Pitfall!: 255 connected screens, reward every ~500 steps
  • Venture: rooms locked until sub-goals met

03 · Core Idea

Random Network Distillation

Two networks with identical architecture but different roles:

Target (Fixed) f: 𝒮 → ℝᵏ
→
Predictor (Trained) f̂θ: 𝒮 → ℝᵏ
Intrinsic Reward Signal rⁱ(sₜ) = ‖ f̂θ(sₜ) − f(sₜ) ‖²

Key insight: The predictor only trains on visited states. Novel states are out-of-distribution → high error → high reward. The target is never updated.

This sidesteps the noisy-TV problem: random networks are deterministic, so stochastic states don't generate spurious rewards.

04 · System Architecture

Combined Extrinsic + Intrinsic Learning

EXTRINSIC STREAM

Standard game reward rᵉ from environment. Uses discounted returns with γᵉ = 0.999.

Handles long-horizon task structure — survive, collect keys, reach exit.

INTRINSIC STREAM

RND bonus rⁱ = prediction error. Uses non-episodic returns with γⁱ = 0.99.

Encourages visiting new rooms across episode boundaries — vital for deep exploration.

Both streams feed into a PPO (Proximal Policy Optimization) backbone with separate value heads for extrinsic and intrinsic rewards:

Dual Value Head Objective Vₜₒₜₐₗ = Vᵉ(s) + Vⁱ(s)
Rₜₒₜₐₗ = rᵉₜ + β · rⁱₜ   (β tuned per env.)

Observation preprocessing: random CNN features on 84×84 grayscale frames. Running mean/std normalization applied to both observations and intrinsic rewards to stabilize training.

05 · Key Properties
  • No dynamics model — avoids model errors
  • Deterministic bonus — immune to noisy-TV
  • Computationally cheap — one forward pass
  • Plug-and-play — works with any RL algorithm
  • Non-episodic intrinsic — crosses episode boundaries
  • Parallel rollouts — 128 environments simultaneously
Observation Normalization
Running Stats ō = (o − μ̂) / √(σ̂² + ε)
clipped to [−5, 5]

Prevents early saturation of the intrinsic bonus when reward scale varies significantly across training.

08 · Research Proposal

Extensions We Propose

  • RND in Continuous Control: Apply to MuJoCo locomotion with sparse rewards — does intrinsic curiosity help when states are continuous?
  • Adaptive β Scheduling: Anneal intrinsic weight β over training; heavy exploration early, exploitation later
  • Multi-head Target Networks: Use an ensemble of random networks to produce smoother, more calibrated novelty estimates
  • Hierarchical RND: Apply RND at multiple temporal scales — room-level and object-level novelty simultaneously
  • Transfer of Predictor: Pre-train predictor on one game family; measure jump-start on new games
